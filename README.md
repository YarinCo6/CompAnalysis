# BJJ Scout

Private intelligence app for BJJ & Grappling competitors.

## Deploy to Render.com (Free)

1. Go to [render.com](https://render.com) → Sign up with GitHub
2. Click **New → Web Service**
3. Connect your GitHub repo (`YarinCo6/CompAnalysis`)
4. Render auto-detects `render.yaml` — confirm settings
5. Add these **Environment Variables**:
   - `NEXTAUTH_URL` → your Render URL (e.g. `https://bjj-scout.onrender.com`)
   - `APP_USERNAME` → your chosen username
   - `APP_PASSWORD` → your chosen password
6. Click **Deploy**

> The `NEXTAUTH_SECRET` is auto-generated by Render.

## Local Development

```bash
cp .env.local.example .env.local
# Edit .env.local with your credentials
npm install
npx playwright install chromium
npx prisma db push
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
